# Vehicle Service Booking System

A full-stack web application for managing vehicle service bookings.

## Technologies Used

### Frontend
- React.js
- Vite
- HTML
- CSS
- JavaScript

### Backend
- Java
- Spring Boot
- Spring Security
- JWT
- Spring Data JPA
- Hibernate

### Database
- MySQL

## Features

- User Registration
- User Login
- JWT Authentication
- Vehicle Management
- Vehicle Service Booking
- Booking Status Management
- REST APIs

## System Architecture

React Frontend → Spring Boot REST API → MySQL Database

## API Modules

- Authentication API
- User API
- Vehicle API
- Booking API
